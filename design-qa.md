# Visual QA — Новая репетиция

## Проверка

- [x] Десктопная композиция: боковая навигация, верхняя панель, контекст, параметры и нижняя панель запуска выстроены в едином стеклянном интерфейсе.
- [x] Контекст разделён на вакансию и опыт кандидата; для ручного сценария используется поисковый комбобокс ролей.
- [x] Карточки длительности, уровня, фокуса и стиля имеют плотную сетку, активное состояние и заметный индикатор выбора.
- [x] Загрузчики резюме и вопросов используют скрытые file-input и не показывают системный контрол в интерфейсе.
- [x] Проверены desktop- и mobile-брейкпоинты, отсутствие ошибок в консоли и создание сценария из выбранной роли.

## Итог

Страница соответствует согласованной композиции и интерактивным состояниям. Извлечение данных из резюме и вопросов проходит через API, а выбранные настройки сохраняются в создаваемом сценарии.
