# CLAUDE.md

Инструкции для Claude Code в проекте «Гласно». Общие правила, безопасность и архитектура находятся в `AGENTS.md` и имеют приоритет.

## Правила использования

- Не запускай автоматически `brainstorming` и `writing-plans`; используй их только по явной просьбе пользователя.
- Не используй `ANTHROPIC_API_KEY`, ключи AI-провайдеров приложения, relay-секреты и платёжные секреты для служебных задач.
- Для анализа и генерации используй активную подписочную сессию Claude Code.
- После изменений не создавай и не отправляй коммиты: пользователь сам проверяет рабочее дерево и создаёт коммит. Исключение — явное поручение пользователя создать конкретный коммит.
- Если пользователь отдельно поручит создать коммит, пиши краткое предметное сообщение на естественном русском языке без шаблонных формулировок и упоминаний инструментов, агентов, сессий или способа генерации.
- Если пользователь отдельно поручит создать ветку, используй короткое смысловое имя в kebab-case и один из рабочих префиксов: `features/` для новой возможности, `bugfix/` для обычного исправления дефекта или `hotfix/` для срочного исправления, которое направляется в production в обход `development`. Не используй служебные префиксы, включая `codex/`, `claude/` и `ai/`.
- Каждую новую задачу начинай с отдельной ветки до изменения кода. Не добавляй к имени служебные слова, номера задач или хеш-коды: например, `features/interview-workspace`. Сливай ветку в целевую только после явного согласования пользователя.
- До изменений обязательно прочитай `AGENTS.md`, этот файл и `.docs/ТЕХНИЧЕСКОЕ_ЗАДАНИЕ.md`. ТЗ — единственный источник этапов и критериев React-версии.
- Для сверки поведения JobAI используй только ветку `develop` в режиме чтения. Галочки ТЗ меняй лишь после успешных проверок и только для точного существующего пункта.

## Команды

```bash
pnpm dev      # локальный Vite-сервер
pnpm build    # проверка TypeScript и production-сборка
pnpm lint     # ESLint
```

После подключения тестовой среды используй `pnpm test` для релевантных тестов. Не устанавливай зависимости и не запускай тяжёлые команды без связи с текущей задачей.

## Serena

Hooks из `.claude/settings.json` активируют Serena в начале сессии, напоминают о ней перед инструментами и очищают состояние в конце. Начинай навигацию с символов и references, но перед удалением или переименованием всегда проверяй использование текстовым поиском: JSX и динамические импорты могут быть не видны symbol search.

## Узкий агент локализации

`.claude/agents/i18n-sweeper.md` запускается только по явной просьбе пользователя и только после появления i18next-конфигурации. Он выполняет read-only аудит пользовательских строк и не изменяет код.
