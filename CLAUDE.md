# CLAUDE.md

Инструкции для Claude Code в проекте «Гласно». Общие правила, безопасность и архитектура находятся в `AGENTS.md` и имеют приоритет.

## Правила использования

- Не запускай автоматически `brainstorming` и `writing-plans`; используй их только по явной просьбе пользователя.
- Не используй `ANTHROPIC_API_KEY`, ключи AI-провайдеров приложения, relay-секреты и платёжные секреты для служебных задач.
- Для анализа и генерации используй активную подписочную сессию Claude Code.
- Не отправляй коммиты в удалённый репозиторий без явного запроса пользователя.

## Команды

```bash
pnpm dev      # локальный Vite-сервер
pnpm build    # проверка TypeScript и production-сборка
pnpm lint     # ESLint
```

После подключения тестовой среды используй `pnpm test` для релевантных тестов. Не устанавливай зависимости и не запускай тяжёлые команды без связи с текущей задачей.

## Serena

Hooks из `.claude/settings.json` активируют Serena в начале сессии, напоминают о ней перед инструментами и очищают состояние в конце. Начинай навигацию с символов и references, но перед удалением или переименованием всегда проверяй использование текстовым поиском: JSX и динамические импорты могут быть не видны symbol search.

## Узкий агент локализации

`.claude/agents/i18n-sweeper.md` запускается только по явной просьбе пользователя и только после появления i18next-конфигурации. Он выполняет read-only аудит пользовательских строк и не изменяет код.
