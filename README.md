# Гласно

Веб-приложение для практики технических интервью и разбора результатов.

## Запуск

```bash
pnpm install
pnpm dev
```

### Локальное подключение к API интервью

Чтобы использовать серверный контур интервью в режиме разработки, настройте
переменные окружения backend локально, запустите backend на указанном порту и
перезапустите Vite. Ключи провайдера и другие секреты остаются только в
окружении backend: в React-приложение они не добавляются.

## Проверки

```bash
pnpm lint
pnpm test:run
pnpm build
```
